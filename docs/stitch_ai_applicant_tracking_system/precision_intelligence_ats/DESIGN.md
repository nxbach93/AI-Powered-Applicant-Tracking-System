## Brand & Style

This design system delivers a refined, high-density enterprise workspace for recruiting teams, hiring managers, and talent intelligence specialists. Merging the focused speed of Linear, the systematic clarity of Notion, and the structural rigor of Ashby, it removes decorative friction in favor of scannable information, precise telemetry, and swift candidate workflow orchestration.

### Brand Personality & Emotional Impact
- **Surgical Precision:** Every metric, match score, and stage indicator aligns to strict visual anchors, projecting total data reliability.
- **Calm Velocity:** Fast micro-interactions, low visual noise, and subtle borders maintain recruiter focus across high-volume pipelines.
- **Augmented Clarity:** AI-driven insights appear contextual and earned, utilizing distinct visual tokens that clearly demarcate machine analysis from human review.

### Design Movement & Mechanics
- **Modern Enterprise Minimalist:** Heavy reliance on structural tabular grids, crisp 1px hairpins, muted slate canvas layers, and intentional contrast scales.
- **Vietnamese Language Optimization:** Typography, line heights, and horizontal spacing accommodate Vietnamese diacritics and variable word lengths without truncation or baseline clipping.

## Colors

The palette balances clinical legibility with distinct semantic signals for operational hiring pipelines.

### Canvas & Structural Neutrals
- **Canvas Base:** `#FFFFFF` (Primary working sheets, modal interiors, elevated cards)
- **Canvas Sub-surface:** `#F8FAFC` (Sidebar, global table headers, page background)
- **Canvas Inset / Active Well:** `#F1F5F9` (Nested filters, token trays, hover wells)
- **Borders & Dividers:** Crisp hairline `#E2E8F0` for structural divisions; `#CBD5E1` for hover states and focused boundaries.
- **Text & Foreground:** Deep Slate `#0F172A` (Headings, primary data), Slate `#334155` (Body, labels), Cool Gray `#64748B` (Secondary metadata, timestamps), Muted Slate `#94A3B8` (Placeholders, disabled states).

### Brand & AI Intelligence Accents
- **Primary Operational Accent:** Cobalt `#2563EB` (Primary interactions, standard CTA, active navigation); Hover `#1D4ED8`; Active `#1E40AF`.
- **AI Engine (Đánh giá AI / Trí tuệ nhân tạo):** Indigo `#4F46E5`; Light Wash `#EEF2FF`; Ring `#C7D2FE`. Reserved for match synthesis, automated summary widgets, and predictive candidate scoring.

### Functional Status Indicators
- **Positive / Match / Offer (Đạt / Phù hợp cao):** Emerald `#059669` (Text/Icon); `#10B981` (Solid indicator); Light Tint `#ECFDF5`.
- **Caution / Screening / In Review (Đang xét duyệt / Chờ phản hồi):** Amber `#D97706` (Text/Icon); `#F59E0B` (Solid indicator); Light Tint `#FFFBEB`.
- **Negative / Rejected (Từ chối / Không khớp):** Crimson `#DC2626` (Text/Icon); `#EF4444` (Solid indicator); Light Tint `#FEF2F2`.

## Typography

The typography is built entirely on **Inter**, optimized for density, scan speed, and localized typographic vertical metrics.

### Tabular Numbers & Font Features
All numerical values (AI match percentages, salary figures, candidate counts, pipeline metrics) must enforce OpenType tabular figures:
```css
font-feature-settings: "tnum" 1, "cv02" 1, "cv03" 1, "cv04" 1;
```
This guarantees alignment across tabular records, candidate scoreboards, and Kanban column summaries.

### Vietnamese Language Metrics
- **Line Heights:** Set body line heights to a minimum ratio of `1.5` (22px on 14px text) to prevent mark clipping on accented uppercase glyphs (`Ấ`, `Ơ`, `Ứ`, `Ệ`).
- **Letter Spacing:** Tightly calibrated from `-0.02em` on large headlines to positive `+0.01em` on micro-labels (`label-sm`, `label-xs`), preventing character collision on multi-syllable Vietnamese terms (e.g., *Tuyển dụng*, *Đánh giá hồ sơ*).

## Layout & Spacing

This design system uses a fluid layout anchored by strict structural baselines, optimized for multi-pane workflows: global navigation, pipeline filters, candidate lists, and contextual preview drawers.

### Layout Mechanics
- **Grid Architecture:** 12-column fluid grid system for dashboard reporting; rigid flex-column mechanics for Kanban boards and split-pane applicant views.
- **Split Screen System:** 
  - Left navigation: fixed 240px (collapsible to 64px icon rail).
  - Main workspace: fluid flex container.
  - Inspection Drawer (CV review & AI assessment): overlay or docked right panel (480px or 640px).
- **Responsive Adaptations:**
  - **Desktop (≥ 1280px):** Full multi-pane view (Navigation + Filter list + Table + Quick preview). Gutters scale to `gutter-desktop` (1.5rem).
  - **Tablet (768px – 1279px):** Filter rail converts to an off-canvas drawer; inspection panel opens as a full-height overlay sheet.
  - **Mobile (< 768px):** Single-column stacked layout; data tables switch to structured card lists. Margin contracts to `margin` (1rem).

## Elevation & Depth

This design system relies primarily on surface differentiation and crisp boundaries rather than heavy drop shadows, reflecting a modern, high-precision SaaS aesthetic.

### Layering Hierarchy
1. **Level 0 (Base Canvas):** Background `#F8FAFC`. Zero elevation, non-interactive foundation.
2. **Level 1 (Card / Table Surface):** Solid `#FFFFFF` bordered with `1px solid #E2E8F0`. Shadow: `none` or micro-ambient `0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
3. **Level 2 (Hover / Active Cards / Dropdowns):** Solid `#FFFFFF` bordered with `1px solid #CBD5E1`. Shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`.
4. **Level 3 (Candidate Detail Drawer / Modals):** Solid `#FFFFFF` bordered with `1px solid #E2E8F0`. Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`. Paired with a muted overlay of `#0F172A` at 30% opacity.

### AI Visual Aura
AI-augmented panels and predictive scoring widgets utilize a subtle 1px dual border with an inner highlight rather than standard drop shadows:
`box-shadow: inset 0 0 0 1px rgba(79, 70, 229, 0.12), 0 1px 3px 0 rgba(79, 70, 229, 0.06);`

## Shapes

The interface leverages compact, purposeful corner radiuses that reinforce efficiency, structural density, and modular components.

- **Base Corner Radius (0.25rem / 4px to 6px):** Standard inputs, small badges, table selection row markers, and buttons.
- **Card & Surface Radius (`rounded-lg` / 0.5rem / 8px):** Candidate record cards, Kanban lane items, modal containers, and docked action bars.
- **Pill Radius (`rounded-full`):** Reserved exclusively for status indicators, pipeline stage pills, and AI match tags to contrast against structural rectangular containers.

## Components

### Buttons
- **Primary:** Background `#2563EB`, text `#FFFFFF`, radius 6px, height 36px (compact) or 32px (dense). Hover `#1D4ED8`. Active `#1E40AF`.
- **Secondary / Outline:** Background `#FFFFFF`, border `1px solid #E2E8F0`, text `#334155`. Hover background `#F8FAFC`, border `#CBD5E1`.
- **AI Action (e.g., "Phân tích CV", "Tóm tắt ứng viên"):** Background `#4F46E5`, text `#FFFFFF`. Hover `#4338CA`. Often paired with a 14px leading sparkle icon.
- **Destructive:** Background `#FFFFFF`, border `1px solid #FCA5A5`, text `#DC2626`. Hover background `#FEF2F2`.

### Badges & Chips (Thẻ trạng thái)
- **Compact structure:** Height 22px, font size 12px, font weight 500, radius 9999px (pill), horizontal padding 8px.
- **High Match / Đạt (Emerald):** Background `#ECFDF5`, border `1px solid #A7F3D0`, text `#065F46`.
- **Reviewing / Đang duyệt (Amber):** Background `#FFFBEB`, border `1px solid #FDE68A`, text `#92400E`.
- **Rejected / Không đạt (Crimson):** Background `#FEF2F2`, border `1px solid #FECACA`, text `#991B1B`.
- **AI Match Score Badge:** Background `#EEF2FF`, border `1px solid #C7D2FE`, text `#3730A3`. Displayed with numeric tabular weight (e.g., `94% Khớp`).

### Form Inputs & Selectors
- **Input Fields:** Height 36px (32px in dense data tables). Border `1px solid #E2E8F0`, background `#FFFFFF`, radius 6px, text `#0F172A`, placeholder `#94A3B8`.
- **Focus State:** Border `#2563EB`, box-shadow `0 0 0 2px rgba(37, 99, 235, 0.15)`. No default browser rings.
- **Inline Search Input:** Contains leading search icon in `#64748B` with embedded keyboard shortcut badge (`⌘K` / `Ctrl+K`) right-aligned.

### Checkboxes & Radios
- **Checkbox:** 16px × 16px square, radius 4px, border `1px solid #CBD5E1`. Checked state: background `#2563EB`, border `#2563EB`, centered white check mark.
- **Radio:** 16px × 16px circle, border `1px solid #CBD5E1`. Checked state: border `#2563EB`, centered `#2563EB` solid pip (6px).

### Data Tables & Candidate Lists
- **Header:** Height 36px, background `#F8FAFC`, border-bottom `1px solid #E2E8F0`, text `#64748B`, font size 12px, font weight 600, uppercase letter-spacing `0.02em`.
- **Row:** Height 48px, background `#FFFFFF`, border-bottom `1px solid #F1F5F9`. Hover background `#F8FAFC`. Selected background `#EFF6FF`.
- **Cells:** Vertical alignment center, padding 0 12px. Tabular values aligned strictly right; strings and candidate profiles aligned left.

### ATS Domain Components
- **Pipeline Stage Progression Bar (Quy trình tuyển dụng):** Segmented horizontal pipeline tracker showing progression (Hồ sơ mới → Duyệt hồ sơ → Phỏng vấn → Đề xuất → Nhận việc). Completed stages in `#059669`, current stage in `#2563EB`, upcoming stages in `#E2E8F0`.
- **AI Assessment Card (Đánh giá AI):** Border `1px solid #E0E7FF`, background `linear-gradient(180deg, #FFFFFF 0%, #F5F7FF 100%)`, radius 8px, padding 16px. Includes candidate key strengths, risk flags, and an explainable match breakdown across skills, experience, and education.
